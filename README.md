# PrimeCore Tech storefront

A modern computer store landing page designed for a Shopify-style niche business selling premium desktops, workstations, laptops, and tech accessories.

## Included sections
- Hero section with CTA
- Featured computer products
- Professional portfolio showcase
- Business milestones timeline
- About section with stats
- Contact form and office details

## Open it locally
Open the file directly in a browser:
- `index.html`

Or serve it from a local folder with any static web server.

## Customization
Edit the product data in `script.js` and update the content in `index.html` to match your own brand, pricing, and contact details.
